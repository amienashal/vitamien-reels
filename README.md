# vitamien-reels

Mesin produksi Reels **Salah Kaprah Vitamin** untuk @vitamien.io (Remotion + ElevenLabs).

- `src/Mascot.tsx` Vitaboy · `src/Villain.tsx` Hoaksin · `src/Cast.tsx` Probi, Eri, Imu, Si Radikal, Viro, Cacing Licik, Om Forward
- `src/Ep1.tsx`, `src/Ep2.tsx` contoh episode (pola yang ditiru episode baru)
- `public/fonts` font lokal (Chrome render tidak bisa mengambil Google Fonts)
- `RUNBOOK.md` langkah produksi otomatis

Render: `npm i && npx remotion render EpN out/epN.mp4`
